# 🚀 Criando um Dashboard de Vendas do Xbox com Excel
Projeto desenvolvido como requisito para conclusão do Bootcamp "Santander - Excel com Inteligência Artificial". Este projeto consiste em um dashboard para dados de vendas de X-Box Game Pass.

Uma ferramenta de fácil utilização para visualização de informações relevantes para empresas, feito em Excel
